# Triage Labels

Canonical labels used by the `triage` skill. All use their default names:

| Label | Purpose |
|-------|---------|
| `needs-triage` | Maintainer needs to evaluate |
| `needs-info` | Waiting on reporter response |
| `ready-for-agent` | Fully specified, AFK agent can pick up |
| `ready-for-human` | Needs human implementation |
| `wontfix` | Will not be actioned |

Labels are created on first use. If the repo later adopts custom label names, update this file.
